6 sections, 68 real transactions, 8 bills, 4 savings goals, zero build, fully offline, about 73 KB total.

Hearth & Ledger is a complete household budget site that runs entirely offline from its own files: six sections — Overview, Budget, Ledger, Bills, Goals and Insights — over one shared household ledger. Every figure is computed from the same store, so income minus spending always equals the balance shown, category totals always equal total spending, and adding a transaction, paying a bill or feeding a goal rewrites every page at once. No build step, no network requests, no account: open it on a desktop or a phone and it just works.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
